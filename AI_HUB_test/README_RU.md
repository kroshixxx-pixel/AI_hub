# AI HUB — тестовый Telegram-бот

Первая локальная версия: выбор бесплатных моделей OpenRouter, отдельные диалоги и локальное сохранение истории в SQLite.

## Важно о бесплатности

Бот загружает только модели с явным суффиксом `:free` и нулевой ценой входа/выхода в каталоге OpenRouter. Это не означает безлимитную работу: бесплатные модели могут иметь дневные/минутные ограничения и иногда временно недоступны. Бот не выбирает платные модели автоматически.

По текущим правилам OpenRouter бесплатные варианты ограничены по частоте; лимиты могут меняться. Не добавляйте платёжные данные и не покупайте кредиты для этого теста.

## Установка на Windows 10

1. Установи Python 3.12 или новее с официального сайта Python, если он ещё не установлен.
2. Распакуй архив в отдельную папку, например `C:\AI-HUB`.
3. Открой эту папку в Проводнике, щёлкни по адресной строке, введи `cmd` и нажми Enter.
4. Выполни по очереди:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
notepad .env
```

5. В `.env` укажи:
   - `BOT_TOKEN` — токен своего Telegram-бота от BotFather.
   - `OPENROUTER_API_KEY` — API-ключ OpenRouter.
   - `OWNER_ID` пока можно оставить пустым для теста. Для личного использования лучше вписать свой Telegram user ID, чтобы ботом не пользовались посторонние.
6. Сохрани `.env` и закрой Блокнот.
7. Запусти:

```bat
.venv\Scripts\python.exe bot.py
```

8. Открой своего бота в Telegram и отправь `/start`.

## Что уже есть

- Кнопки главного меню.
- Динамический список доступных бесплатных моделей `:free`.
- Отдельные диалоги.
- Автосохранение пользовательских и модельных сообщений в SQLite.
- Возврат к ранее сохранённому чату после перезапуска.
- Контекст последних 24 сообщений при продолжении диалога.

## Что пока не реализовано

- Удаление и переименование через кнопки.
- Поиск по истории.
- Экспорт в TXT.
- Защита от параллельных запросов.
- Автоматическая очистка/архивация старых данных.
- Запуск в фоне и автозапуск Windows.

## Безопасность

- Никогда не отправляй токены Telegram или API-ключи в чат и не публикуй `.env`.
- Не загружай `.env` в GitHub.
- Не используй этот тестовый бот как публичный сервис.
- Не отправляй через бесплатные сторонние API пароли, личные документы или конфиденциальные данные.
- Если ключ случайно попал в открытый доступ, отзови его в кабинете соответствующего сервиса.

## Диагностика

Если бот завершился с ошибкой, сохрани весь текст из окна CMD. Не закрывай окно до копирования ошибки.
