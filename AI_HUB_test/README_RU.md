# AI HUB — тестовый Telegram-бот

Локальный Telegram-бот для общения с бесплатными вариантами моделей OpenRouter, отдельными диалогами и сохранением истории в SQLite.

## Как устроен доступ

- При первом запуске пользователь отправляет боту `/start`.
- Бот просит общий пароль из `.env`.
- После правильного ввода Telegram ID пользователя сохраняется в локальной SQLite-базе.
- При следующих запусках пароль этому пользователю повторно не нужен.
- Пока пользователь не авторизован, команды, сообщения и inline-кнопки бота недоступны.

Пароль задаётся владельцем в `.env` через параметр `ACCESS_PASSWORD`. Не публикуй пароль в GitHub и не отправляй его в открытые чаты. Передавай его только тем, кому действительно хочешь дать доступ.

**Важно:** все пользователи используют один OpenRouter API-ключ владельца. Их запросы расходуют общую квоту и могут упереться в общие лимиты бесплатных моделей.

## Важно о бесплатности

Бот загружает модели с явным суффиксом `:free` и нулевой ценой входа/выхода в каталоге OpenRouter. Это не гарантирует безлимитную работу: бесплатные модели могут иметь ограничения и временно становиться недоступными. Бот не выбирает платные модели автоматически.

## Установка на Windows 10

1. Установи Python 3.12 или новее, если он ещё не установлен.
2. Распакуй папку проекта.
3. Открой папку `AI_HUB_test` в Проводнике, щёлкни по адресной строке, введи `cmd` и нажми Enter.
4. Выполни по очереди:

```bat
py -3.12 -m venv .venv
.venv\\Scripts\\python.exe -m pip install --upgrade pip
.venv\\Scripts\\python.exe -m pip install -r requirements.txt
copy .env.example .env
notepad .env
```

5. В открывшемся файле `.env` укажи:
   - `BOT_TOKEN` — токен Telegram-бота от BotFather.
   - `OPENROUTER_API_KEY` — API-ключ OpenRouter.
   - `ACCESS_PASSWORD` — придуманный тобой длинный уникальный пароль для пользователей.
6. Сохрани `.env` и закрой Блокнот.
7. Запусти:

```bat
.venv\\Scripts\\python.exe bot.py
```

8. Открой бота в Telegram и отправь `/start`. Введи пароль из `.env`.

## Что уже есть

- Главное меню с inline-кнопками.
- Динамический список доступных бесплатных моделей `:free`.
- Отдельные диалоги для каждого Telegram-пользователя.
- Автосохранение сообщений в SQLite.
- Возврат к сохранённым чатам после перезапуска.
- Контекст последних 24 сообщений.
- Общая парольная авторизация с сохранением разрешённых Telegram ID в SQLite.

## Пока не реализовано

- Удаление и переименование чатов через кнопки.
- Поиск по истории.
- Экспорт в TXT.
- Автоматическая очистка/архивация старых данных.
- Запуск в фоне и автозапуск Windows.

## Безопасность

- Никогда не отправляй токены Telegram или API-ключи в чат и не публикуй файл `.env`.
- Не загружай `.env` в GitHub. В репозитории есть только безопасный шаблон `.env.example`.
- Доступ к боту общий: не передавай пароль незнакомым людям.
- Не отправляй через сторонние API пароли, личные документы или конфиденциальные данные.
- Если ключ случайно попал в открытый доступ, отзови его в кабинете соответствующего сервиса.

## Диагностика

Если бот завершился с ошибкой, сохрани весь текст из окна CMD. Не закрывай окно до копирования ошибки.
